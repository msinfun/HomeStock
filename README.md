# 老管家先生 (Mr. Housekeeper) 🏡✨

老管家先生是一款專為追求生活品味與極致效率的家庭所設計的 **廚房與庫存智慧管理系統**。透過最尖端的 AI 視覺辨識與成本估算引擎，結合極盡苛求的「**蘋果原生玻璃擬物化 (Premium Native iOS Glassmorphism)**」設計語彙，讓您掌管每一個家計細節都成為一種沈浸式的頂級享受。

---

## 🌟 頂級 UI/UX 設計語彙 (Premium Native iOS Glassmorphism)

本專案全面採用極致的毛玻璃風格，為使用者帶來順滑、沉浸且具備現代科技感的操作體驗。

* **極致毛玻璃質感**：全面導入 `backdrop-blur-[40px]` 與 `bg-white/80`，配合高飽和度底色，創造出宛如原生 iOS 系統般的光學邊緣與景深層次。
* **流暢的微動畫交互 (Micro-Interactions)**：滑動回饋、按鈕收放 (`active:scale-95`) 與精心調校的彈窗進場動畫，皆力求如絲綢般平滑。
* **防滾輪誤觸機制 (Scroll-Proof Inputs)**：系統內所有的 `<input type="number">` 皆嚴格掛載了 `onWheel={e => e.currentTarget.blur()}`，徹底防止使用者在捲動頁面時意外修改數量、份量或金錢等重要財務/庫存數據。

---

## 🔥 核心強大功能 (Core Features)

### 📦 庫存與食材管理 (Inventory)
* **虛擬身分證機制 (Persistent Identity)**：不再擔心辛勞記錄的心得消失！當食材數量被扣至 0 時，系統不會強制刪除該項目，而是自動將其轉為 `__empty` 空箱狀態並永久保留。這讓您過去記錄的購買價格、照片、筆記與評價能夠如金庫般留存，方便下次補貨時馬上參考。
* **高效批次管理 (Batch Operations)**：支援左下角一鍵啟動「批次模式」。並透過極具原生 iOS 風格的懸浮下拉選單，快速勾選多筆項目來批次調整分類與存放位置，大幅節省時間。
* **文字/網址快速匯入 (Smart Import)**：不想慢慢打字？您可以直接貼上 YouTube 影片網址或任何長篇食譜文字，AI 會在幕後嚴格過濾、理解內容，並精準輸出標準 JSON 格式自動為您建檔。
* **智慧份量估算 (Smart Servings AI)**：新增食譜時，AI 引擎會自動掃描您的食譜圖片或長短文本。根據食材總重量與料理常理，為您「自動推算」這道菜大約是幾人份的餐點，並優雅地顯示在 UI 的絕美 Badge 上。

### 🍳 沉浸式食譜系統 (Recipes)
* **一鍵精美分享 (One-Click Share)**：看到滿意的獨門配方想傳給家人？只需一鍵，系統就會自動將料理名稱、智慧份量、食材清單與「自動編號 (Numbered)」的作法步驟排版成帶有質感 Emoji 的精整文字。甚至會聰明地附上來源網址、總熱量與預估成本，並直接存入您的剪貼簿！
* **食譜智慧副本 (Duplicate Recipe)**：支援一鍵無縫複製食譜。當您想要微調某道經典菜色的食材比例，又想保留原版配方做對照時，副本功能讓您可以輕鬆開出分支版本並獨立重新計算它的獨特成本與營養。
* **智能成本與營養計算 (Cost & Nutrition Estimation)**：引擎與您的庫存金庫深度關聯，AI 將結合頂級市場 (Premium Supermarket) 市價標準，為每份食譜計算出精準的總成本、卡路里與三大巨集營養素 (蛋白質/碳水/脂肪)。

### ⚙️ 全局設定與資料安全 (Settings & Data Security)
* **iOS 分層式選單架構**：設定頁面採用清晰的分層式設計，讓各種個性化設定與資料管理一目了然且充滿高級感。
* **改名連動機制 (Cascading Updates)**：如果您在設定中修改了某個「分類名稱」或「標籤(Tag)名稱」，全系統資料庫將會自動無縫同步。過去的所有庫存與食譜都會瞬間換上新名字，徹底杜絕資料斷層。
* **雙軌備份大師 (Dual Backup System)**：
  * **JSON 完整備份**：支援完整匯出系統還原檔。匯入時更具備「**智能合併 (Merge)**」與「**完全覆蓋 (Overwrite)**」雙模式，確保您的心血永不遺失且充滿彈性。
  * **Excel 報表匯出入**：支援匯出成標準 Excel 試算表，方便您在個人電腦上進一步作帳理財。

## 🛠️ 架構與技術棧 (Tech Stack)

本系統堅持 **Local-First (本地優先)** 的最高隱私架構理念，您的所有敏感資料與庫存資產皆保存在您的設備中，不經過第三方伺服器，帶來極致流暢與 100% 的安全感。

* **前端框架 (Frontend)**: React (Functional Components & Hooks)
* **樣式系統 (Styling)**: Tailwind CSS (深度的 Native iOS 玻璃質感擴展)
* **資料儲存 (Storage)**: 現代瀏覽器的 LocalStorage API (Local-First Architecture)
* **AI 驅動核心 (AI Engine)**: Google Gemini API (負責智慧解析、圖片光學辨識、成本估算與精準標籤推論)
* **建置工具 (Build Tool)**: Vite (極速熱更新與模組打包)
